# Art direction — «Котик Біт» × informatic.website

**Format:** 1080×1920 (9:16), 30 fps, ~32 s, Ukrainian.
**Design read:** cosy-cartoon edtech for teens; warm, round, bouncy. Not corporate.

## Taste profile
- visual_variance: high (each scene has a different primary subject)
- motion_intensity: high, cartoon physics (anticipation, squash & stretch, overshoot)
- information_density: low (one idea per beat)
- reference strategy: none (site unreachable from this session) — original look
- anti-patterns: stock text cards, slide-like layouts, flat linear easing, doubled captions

## Palette
- Night indigo `#1E1B4B`, violet `#6D28D9`, lilac `#A78BFA`
- Mint `#34D399` (code / success), sunny `#FBBF24`, coral `#FB7185`
- Cat: ginger `#F59E0B` → `#EA7A12`, cream `#FFF1D6`, blush `#FDA4AF`

## Type
Nunito 900/800 (rounded, Cyrillic) for everything; JetBrains Mono for code.

## Character
Біт — chibi ginger cat, front view, huge eyes, mint collar with a `</>` tag.
Rig: tail, body, two arms (shoulder pivots), head (neck pivot), two ears, eyes
(blink/happy/wink/confused), pupils (gaze), brows, mouth (smile ↔ open), blush, whiskers.

## Signature device
The blinking text cursor `▍` — it appears on the laptop screen at the start,
in the address bar of the site, and at the end of the typed code. Scarce: 3 beats.

## Voice
No human voice (narration CDN unreachable). The cat "speaks" in synthesized
syllable blips with speech bubbles that type in exactly on each syllable.

## Scenes (distinct primary subjects)
1. **Laptop** — cat pops up from behind a glowing laptop, meows, waves.
2. **Swirl of symbols** — close-up, confused cat, code symbols orbit; purr → they burst into stars.
3. **Phone with the site** — address bar types informatic.website; Уроки / Тести / Задачі cards pop.
4. **Staircase** — cat hops 3 steps, code window types `print("Привіт, світ!")`, confetti.
5. **CTA** — sunburst, waving cat, URL pill + Instagram @informatic_it card, final wink.

Transitions: mint iris wipe from the cat's position.
